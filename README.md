C DSA assignment -stack and circular queue


 Q1. Stack Using Array
 
 Introduction
A stack is a linear data structure that follows LIFO
(Last In First Out).

 Operations
- PUSH
- POP
- PEEK
- DISPLAY

 Overflow
Stack Overflow occurs when we try to insert an element
into a full stack.

 Underflow
Stack Underflow occurs when we try to delete an element
from an empty stack.

Time Complexity
PUSH: O(1)
POP: O(1)
PEEK: O(1)
DISPLAY: O(n)

 Space Complexity
O(n)

 Q2. Circular Queue Using Array

 Introduction
A circular queue is a queue in which the last position
is connected back to the first position.

 Operations
- ENQUEUE
- DEQUEUE
- FRONT
- DISPLAY

Time Complexity
ENQUEUE: O(1)
DEQUEUE: O(1)
FRONT: O(1)
DISPLAY: O(n)

Space Complexity
O(n)

 Advantage over Linear Queue
Circular queue makes better use of available memory because
unused positions at the beginning can be reused.
